# VIPBridge Commands

## Players

- `/tokens` — The one place for owned tokens, token redemption, HeadDB selection, and completed deliveries.
- `/tokenshop` — Buy available tokens with server money.
- `/vip` — Short VIP reward guide. VIP is a reward source, not a separate token system.

HeadDB does not need its own command: click a HeadDB token in `/tokens`. Finished rewards do not need their own command: click **Deliveries** in `/tokens`.

## Staff

Administrative tools remain under `/vip` and require `vipbridge.admin`. They are hidden from normal-player tab completion.
